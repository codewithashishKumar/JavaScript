# JavaScript 

A structured collection of **JavaScript frontend concepts, examples, and notes**.

This repository is focused on understanding JavaScript from a **frontend development perspective**, starting from the fundamentals and progressing toward advanced concepts used in modern web applications.

---

## What is JavaScript?

**JavaScript** is a high-level, dynamically typed programming language primarily used to make web pages **interactive, dynamic, and responsive**.

In frontend development, JavaScript works together with:

* **HTML** → Structure
* **CSS** → Styling
* **JavaScript** → Logic & Interactivity

JavaScript allows us to handle user interactions, manipulate the DOM, validate forms, communicate with APIs, create dynamic UI components, and build complete web applications.

## 13. JavaScript Modules

Learn how to organize frontend code into reusable modules.

```javascript

export function add(a, b) {
  return a + b;
}
```

```javascript

import { add } from "./math.js";

console.log(add(10, 20));
```
