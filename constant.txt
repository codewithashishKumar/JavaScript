1. DEFINITION
const is a JavaScript keyword used to create a variable whose value cannot be reassigned after it has been created.

2. EASY SIMPLE DEFINITION
const creates a variable that cannot be given a new value later.

3. CREATING A const VARIABLE
Example:

const name = "John";

Here:
const → creates a variable that cannot be reassigned
name → variable name
= → assigns a value
"John" → value

4. USING const
Example:

const country = "India";

console.log(country);

The variable can be used normally.

5. REASSIGNING const
A const variable cannot be reassigned.

Example:

const country = "India";

country = "USA";

This is not allowed because country was created with const.

6. let VS const
let can be reassigned:

let age = 20;
age = 21;

const cannot be reassigned:

const age = 20;
age = 21;

7. WHEN TO USE const
Use const when you do not plan to reassign the variable.

Examples:

const birthYear = 2000;
const daysInWeek = 7;
const country = "India";

8. WHEN TO USE let
Use let when the value needs to change.

Example:

let score = 10;
score = 20;

9. IMPORTANT BEGINNER RULE
let → can be reassigned
const → cannot be reassigned

10. WHAT I LEARNED
- const creates a variable.
- A const variable cannot be reassigned.
- const can store text, numbers, and other types of values.
- Use const when you do not plan to reassign a variable.
- Use let when the value needs to change.
- Trying to reassign a const variable causes an error.


Difference between var, let and const

| Feature                     | `let`           | `const`               | `var`            |
| --------------------------- | --------------- | --------------------- | ---------------- |
| Creates variable            | ✅               | ✅                     | ✅                |
| Reassignment                | ✅               | ❌                     | ✅                |
| Redeclaration in same scope | ❌               | ❌                     | ✅                |
| Block scoped                | ✅               | ✅                     | ❌                |
| Modern recommendation       | ✅               | ✅                     | ⚠️ Usually avoid |
| Common use today            | Changing values | Values not reassigned | Older code       |
