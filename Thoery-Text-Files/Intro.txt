JavaScript is a high-level, dynamically typed programming language used mainly to build interactive and dynamic web applications. 
It runs in browsers and can also be used on the server side with Node.js. 
It supports concepts like functions, objects, asynchronous programming, events, and DOM manipulation.
========================================
JAVASCRIPT - TOPIC 1: INTRODUCTION
========================================
1. DEFINITION
JavaScript is a programming language used to make websites and web applications interactive and dynamic.

2. EASY SIMPLE DEFINITION
JavaScript tells a website what to do.

Think of a website like a human body:
HTML = Structure / Skeleton
CSS = Appearance / Style
JavaScript = Behavior / Actions

3. WHAT CAN JAVASCRIPT DO?
JavaScript can:
- Respond when you click a button
- Change text on a webpage
- Show or hide things
- Perform calculations
- Create animations
- Validate forms
- Fetch data from a server
- Build web applications

4. YOUR FIRST JAVASCRIPT CODE
console.log("Hello World");
OUTPUT:
Hello World

5. WHAT IS console.log()?
console.log() is used to display something in the JavaScript console.

Example:
console.log("Pizza");
OUTPUT:
Pizza

Another example:
console.log("I am learning JavaScript");
OUTPUT:
I am learning JavaScript

6. JAVASCRIPT CAN PERFORM CALCULATIONS
Example:
console.log(5 + 3);
OUTPUT:
8

Another example:
console.log(10 + 5);
OUTPUT:
15

7. IMPORTANT CONCEPT
console.log() tells JavaScript:
"Display this in the console."

For text:
console.log("Hello");
OUTPUT:
Hello

For a calculation:
console.log(10 + 5);
OUTPUT:
15

8. WHAT I LEARNED
- JavaScript is a programming language.
- JavaScript makes websites interactive.
- JavaScript tells a website what to do.
- console.log() displays something in the console.
- JavaScript can perform calculations.
- Text can be written inside quotation marks.
- JavaScript can work with numbers.

9. PRACTICE
console.log("I am learning JavaScript");
console.log("Pizza");
console.log("Welcome to my shop");
console.log(10 + 5);

A JavaScript engine reads JavaScript code and executes it.

2. EASY SIMPLE DEFINITION

Think of it like this:
JavaScript code = Instructions
JavaScript engine = Executes the instructions

3. EXAMPLE

Hello
15

JavaScript code
      ↓
JavaScript engine
      ↓
Code gets executed
      ↓
Result

You do not need to memorize engine names yet.

6. IMPORTANT CONCEPT
JavaScript code needs a JavaScript engine to execute.

console.log("Hello");

The JavaScript engine reads the code and executes it.

7. WHAT I LEARNED
- JavaScript is a programming language.
- A JavaScript engine executes JavaScript code.
- The engine reads the instructions written in JavaScript.
- Without a JavaScript engine, JavaScript code will not be executed.
- V8 is a popular JavaScript engine.
- Chrome and Node.js use the V8 engine.

You write JavaScript
      ↓

      ↓

JAVASCRIPT - TOPIC 3: YOUR FIRST JAVASCRIPT PROGRAM
========================================
1. DEFINITION
A JavaScript program is a set of instructions written using JavaScript that a JavaScript engine can execute.

2. EASY SIMPLE DEFINITION
A JavaScript program is JavaScript code that tells the computer what to do.

3. JAVASCRIPT CODE VS JAVASCRIPT PROGRAM
JavaScript = Programming language
JavaScript code = Instructions written in JavaScript
JavaScript program = A set of JavaScript instructions that can be executed

Example:
console.log("Hello World");

This is JavaScript code and can be part of a JavaScript program.

4. YOUR FIRST JAVASCRIPT PROGRAM
console.log("Hello World");

OUTPUT:
Hello World

5. MULTIPLE INSTRUCTIONS
JavaScript can contain multiple instructions.

Example:
console.log("Hello");
console.log("My name is Alex");
console.log(10 + 5);

OUTPUT:
Hello
My name is Alex
15

6. EXECUTION ORDER
JavaScript normally executes instructions from top to bottom.

Example:
console.log("First");
console.log("Second");
console.log("Third");

OUTPUT:
First
Second
Third

7. console.log() WITH TEXT AND NUMBERS
JavaScript can display text:
console.log("Hello");

JavaScript can also calculate numbers:
console.log(10 + 5);

OUTPUT:
Hello
15

8. IMPORTANT CONCEPT
JavaScript executes instructions from top to bottom.

Example:
console.log("A");
console.log(10 + 5);
console.log("C");

OUTPUT:
A
15
C

9. WHAT I LEARNED
- A JavaScript program is a set of JavaScript instructions.
- JavaScript code tells the computer what to do.
- console.log() displays information in the console.
- JavaScript executes instructions from top to bottom.
- Multiple console.log() statements execute in order.
- console.log() can display text.
- console.log() can display calculation results.

10. PRACTICE
console.log("My name is John");

JAVASCRIPT - TOPIC 4: STATEMENTS AND COMMENTS
========================================
1. DEFINITION
A statement is an instruction that tells JavaScript to do something.
A comment is text written in JavaScript that JavaScript does not execute.

2. EASY SIMPLE DEFINITION
Statement = An instruction for JavaScript.
Comment = A note for humans that JavaScript ignores.

3. STATEMENTS
Example:
console.log("Hello");
console.log(10 + 5);

OUTPUT:
Hello
15

Both lines are statements because JavaScript executes them.

4. COMMENTS
A single-line comment starts with //.

Example:
// This is a comment
console.log("Hello");

OUTPUT:
Hello

JavaScript ignores the comment and executes the console.log() statement.

5. COMMENT EXAMPLE
// Print a greeting
console.log("Hello");

// Calculate a number
console.log(5 + 5);

OUTPUT:
Hello
10

6. COMMENTED-OUT CODE
A JavaScript statement can be turned into a comment by adding // before it.

Example:
console.log("Start");
// console.log("Middle");
console.log("End");

OUTPUT:
Start
End

The "Middle" line does not execute because it is a comment.

7. IMPORTANT CONCEPT
// means that JavaScript should ignore the rest of that line.

Example:
// This is ignored
console.log("This is executed");

OUTPUT:
This is executed

8. STATEMENT VS COMMENT
Statement:
console.log("Hello");

JavaScript executes it.

Comment:
// Say hello

JavaScript ignores it.

9. WHAT I LEARNED
- A statement is an instruction for JavaScript.
- JavaScript executes statements.
- A comment is a note for humans.
- JavaScript ignores comments.
- // creates a single-line comment.
- Code can be temporarily disabled by adding // before it.

10. PRACTICE
// My first message
console.log("Hello");

// My calculation
console.log(5 + 5);

JAVASCRIPT - TOPIC 5: JAVASCRIPT SYNTAX
========================================
1. DEFINITION
JavaScript syntax is the set of rules that determine how JavaScript code must be written so JavaScript can understand and execute it.

2. EASY SIMPLE DEFINITION
Syntax = The rules for writing JavaScript correctly.

Just like human languages have grammar rules, JavaScript has syntax rules.

3. STATEMENTS
A JavaScript program can contain statements.

Example:
console.log("Hello");
console.log(10 + 5);

A statement is an instruction for JavaScript.

4. STRINGS
Text is usually written inside quotes.

Example:
console.log("Hello");

Double quotes can be used:
console.log("Hello");

Single quotes can also be used:
console.log('Hello');

5. PARENTHESES ()
Parentheses are used in many JavaScript statements and functions.

Example:
console.log("Hello");

The parentheses contain information being passed to console.log().

() = Parentheses

6. CURLY BRACES {}
Curly braces are used in many JavaScript structures.

Example:
if (age >= 18) {
    console.log("Adult");
}

{} = Curly braces

7. SEMICOLON ;
A semicolon is commonly placed at the end of a JavaScript statement.

Example:
console.log("Hello");

JavaScript can often work without semicolons, but we will use semicolons while learning because they make the end of statements clear.

8. COMMENTS
A single-line comment starts with //.

Example:
// This is a comment
console.log("Hello");

JavaScript ignores the comment.

9. IMPORTANT SYNTAX CONCEPT
JavaScript uses specific symbols and structures that must be written correctly.

Example:
console.log("Hello");

The code contains:
console
.
log
(
"Hello"
)
;

The exact meaning of each part will be learned in later topics.

10. JAVASCRIPT SYNTAX VS PROGRAMMING LANGUAGE
JavaScript = Programming language
Syntax = Rules for writing JavaScript

11. WHAT I LEARNED
- Syntax means the rules for writing JavaScript.
- JavaScript code must follow syntax rules.
- Statements are instructions for JavaScript.
- Text can be written inside quotes.
- Parentheses are written as ().
- Curly braces are written as {}.
- Semicolons are written as ;.
- Comments can start with //.
- JavaScript can often work without semicolons.
- We will use semicolons while learning for consistency.
