# JAVASCRIPT LOOPS

Loops are used to repeat a block of code multiple times.

1. FOR LOOP

---

Used when you know how many times you want to repeat something.

Syntax:

for (let i = 0; i < 5; i++) {
console.log(i);
}

Output:
0
1
2
3
4

2. WHILE LOOP

---

Runs while a condition is true.

Example:

let i = 0;

while (i < 5) {
console.log(i);
i++;
}

3. DO...WHILE LOOP

---

Runs the code at least once before checking the condition.

Example:

let i = 0;

do {
console.log(i);
i++;
} while (i < 5);

4. FOR...OF LOOP

---

Used to loop through the VALUES of an array or other iterable.

Example:

const fruits = ["Apple", "Banana", "Orange"];

for (const fruit of fruits) {
console.log(fruit);
}

Output:
Apple
Banana
Orange

5. FOR...IN LOOP

---

Used to loop through the KEYS/PROPERTIES of an object.

Example:

const person = {
name: "John",
age: 25,
city: "Delhi"
};

for (const key in person) {
console.log(key, person[key]);
}

Output:
name John
age 25
city Delhi

NOTE:
Use for...of for arrays.
Use for...in mainly for objects.

6. FOREACH()

---

Runs a function for every element in an array.

Example:

const numbers = [10, 20, 30];

numbers.forEach(function(num) {
console.log(num);
});

Short version:

numbers.forEach(num => console.log(num));

7. MAP()

---

Creates a NEW array by changing each element.

Example:

const numbers = [1, 2, 3];

const doubled = numbers.map(num => num * 2);

console.log(doubled);

Output:
[2, 4, 6]

8. FILTER()

---

Creates a new array containing elements that match a condition.

Example:

const numbers = [1, 2, 3, 4, 5];

const even = numbers.filter(num => num % 2 === 0);

console.log(even);

Output:
[2, 4]

9. REDUCE()

---

Used to reduce an array to a single value.

Example:

const numbers = [1, 2, 3, 4];

const sum = numbers.reduce((total, num) => total + num, 0);

console.log(sum);

Output:
10

## QUICK SUMMARY

for          -> Repeat a known number of times
while        -> Repeat while condition is true
do...while   -> Runs at least once
for...of     -> Loop through array values
for...in     -> Loop through object keys
forEach()    -> Run code for every array element
map()        -> Create a new changed array
filter()     -> Create an array of matching elements
reduce()     -> Convert an array into one value
break        -> Stop the loop
continue     -> Skip current iteration

IMPORTANT:
For modern JavaScript, remember these especially:

for
for...of
for...in
forEach()
map()
filter()
reduce()



| `while`                | `do...while`               |
| ---------------------- | -------------------------- |
| Checks condition first | Runs code first            |
| May run 0 times        | Runs at least 1 time       |
| `while (condition)`    | `do { } while (condition)` |
